# Ecommerce Deportivo

Aplicación Full Stack desarrollada como proyecto final de formación, orientada a la gestión y venta online de productos deportivos.

## Objetivo

Desarrollar una plataforma ecommerce funcional que permita visualizar productos, gestionar compras y procesar pagos mediante Mercado Pago.

## Funcionalidades principales

* Catálogo de productos
* Visualización de detalle de producto
* Carrito de compras
* Gestión de cantidades
* Registro y gestión de usuarios
* Creación y seguimiento de pedidos
* Carga de imágenes de productos
* Integración con Mercado Pago
* Validaciones de negocio
* Interfaz responsive

## Tecnologías utilizadas

### Frontend

* React
* JavaScript
* HTML
* CSS

### Backend

* Node.js
* Express

### Base de datos

* MongoDB

### Integraciones

* Mercado Pago SDK

## Arquitectura

El proyecto fue desarrollado utilizando una arquitectura por capas para separar responsabilidades y facilitar el mantenimiento del código.

Estructura principal:

* Router
* Controller
* Service
* DAO
* Base de datos MongoDB
